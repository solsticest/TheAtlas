ДАЛЁКИЕ ЗЕМЛИ — ATLAS 4.1
========================

ВЕРСИЯ 4.1
Добавлены основная папка проекта, её автоматическое подключение при запуске
и повторное разрешение доступа одной кнопкой, если браузер его сбросил.
Формат данных атласа остаётся версии 4.

ЗАПУСК
Откройте index.html в Opera GX, Chrome или Edge. Сервер, Python, Node.js и
сборка для работы приложения не нужны. Leaflet 1.9.4 загружается с CDN,
поэтому интернет по-прежнему нужен для первоначального открытия страницы.
Нажмите «Открыть папку проекта» и выберите папку с index.html и data/.
При первоначальном запуске до выбора папки отображается демонстрация.

ОСНОВНАЯ ПАПКА
Нажмите «Задать основную папку» и выберите корневую папку существующего
атласа с data/atlas.json. Этот выбор запоминается в IndexedDB браузера.
При следующем открытии той же HTML-страницы в том же профиле браузера
проект загрузится автоматически, если разрешение на доступ сохранилось.
Если браузер сбросил разрешение, нажмите «Подключить основную папку»:
потребуется подтвердить доступ, но искать папку заново не нужно.
Браузер может запретить IndexedDB для локальной страницы или приватного
режима; тогда появится сообщение, и обычное открытие папки останется доступным.
«Забыть основную папку» удаляет только настройку браузера, не файлы проекта.
Обычная кнопка «Открыть папку проекта» позволяет временно открыть другой
проект и не заменяет основную папку. Перенос HTML в другое место, очистка
данных браузера или другой профиль могут потребовать задать папку заново.
Сам JSON атласа и путь к папке не добавляются в настройки проекта или GitHub.

НАВИГАЦИЯ И ПОИСК
Поле поиска над вкладками ищет во всех мирах: названия миров и карт, имена,
краткие описания, текст статей и теги локаций. Нажмите результат для перехода.
Вкладка «Обзор» содержит список маркеров текущего мира по алфавиту и фильтр
по типу. Список включает маркеры, ещё не видимые при текущем масштабе.
При переходе к локации её тип включается, камера приближается до её порога.
Кнопка ☰ теперь находится слева, непосредственно под кнопками зума + и −.

КАРТОЧКИ И СТАТЬИ
Нажатие на маркер открывает краткую карточку. «Подробнее» открывает статью.
Краткое описание и полная статья — независимые поля; старые описания остаются.
«Изменить маркер» открывает прежние настройки имени, типа, цвета и порога.
В редакторе маркера есть также кнопка «Открыть полную статью».

В статье переключайтесь между чтением и редактированием. Поддерживаются:
заголовки, жирный и курсив, списки, цитаты, интернет-ссылки, ссылки на другие
локации, изображения PNG/JPEG/WebP с подписью, теги через запятую.
Изображения статьи копируются в media/ при сохранении на диск.
HTML из буфера обмена очищается: внешние картинки и исполняемое содержимое
не добавляются. Изображение нужно вставлять отдельной кнопкой.

Изменения текста автоматически попадают в текущее состояние атласа.
Закрытие статьи не сбрасывает текст и не меняет камеру. Для записи в папку
нажмите «Сохранить на диск» в статье или в верхней панели. Несохранённые
изменения отмечены в верхней панели. При закрытии страницы браузер выдаёт
предупреждение. Без сохранения на диск перезагрузка потеряет изменения.
Ctrl+Z внутри поля текста оставлен браузеру; вне текстовых полей отменяет
операцию атласа. Отмена в текущем мире сохраняет центр и масштаб карты.

ЛИНЕЙКА
Нажмите «Линейка» справа сверху и отмечайте последовательные точки маршрута.
Показывается общая длина всех отрезков. «Убрать точку» отменяет последнюю.
«Завершить» оставляет линию на карте; «Очистить» удаляет измерение.
Escape прекращает измерение и очищает линию. Измерения временные, не входят
в сохранённые данные и сбрасываются при переключении мира.

До калибровки единицы — пиксели базовой карты. Во вкладке «Мир» задайте
километры на пиксель либо нажмите «Задать по двум точкам», отметьте две
точки и введите известное расстояние. Масштаб независим для каждого мира.
При замене базовой карты изображением другого размера проверьте калибровку.

СОВМЕЩЕНИЕ КАРТ
Во вкладке «Карты-слои» выберите регион с загруженным изображением.
Нажмите «Совместить по двум точкам». Слева появится подробная карта,
справа — родительская карта с базой и её предками.
1. Отметьте первый ориентир слева, затем тот же ориентир справа.
2. Отметьте второй ориентир слева, затем тот же ориентир справа.
3. Нажмите «Применить совмещение».
Выбирайте далеко расположенные и хорошо узнаваемые объекты.
В обоих окнах можно двигать и приближать карту. «Выбрать заново» сбрасывает
точки; закрытие окна отменяет подгонку без изменений данных.
Положение, равномерный масштаб и поворот рассчитываются вместе. Пропорции
берутся из исходного изображения. Деформации и растяжение по отдельным
осям этот инструмент не вычисляет. Результат можно отменить через Ctrl+Z.

Ограничение прежней геометрии сохранено: вложенные карты и маркеры не
наследуют визуальный поворот родительского изображения автоматически.

РЕЖИМ ПРОСМОТРА
Кнопка в верхней панели скрывает инструменты редактирования и отключает
перетаскивание маркеров. Поиск, список локаций, карточки, статьи, перемещение,
масштаб и линейка остаются доступны. Для правок вернитесь в редактор.
Это режим интерфейса, не авторизация и не средство скрытия секретных данных.

СОХРАНЕНИЕ И РЕЗЕРВНЫЕ КОПИИ
Перед перезаписью data/atlas.json его прежнее содержимое записывается в
data/backups/atlas-<дата-время>-<идентификатор>.json. Копии не удаляются
автоматически. Если резервная копия не записалась, основной JSON не заменяется.
Сначала проверяются изображения, затем сохраняются новые файлы и JSON.
Существующие изображения при удалении объектов физически не удаляются.
Если данных или изображений не хватает, ошибка оставляет атлас в памяти.
Если atlas.json изменён извне, перезапись останавливается, чтобы не затереть
чужие изменения. Работайте в одном окне редактора одновременно.

Во время записи сохраняется снимок состояния. Правки, сделанные позже,
остаются с отметкой «Есть изменения» и требуют следующего сохранения.
Не закрывайте окно после ошибки, пока не сохранены нужные данные.
«Экспорт JSON» сохраняет только данные, без изображений. Для полной
резервной копии копируйте всю папку проекта, включая maps/ и media/.

СОВМЕСТИМОСТЬ И ИСХОДНАЯ ВЕРСИЯ
Старые JSON загружаются с добавлением недостающих полей. Неизвестные поля
сохраняются. При записи версия данных становится 4. Добавлены поля:
locations[].article — очищенный HTML статьи;
locations[].tags — массив тегов;
worlds[].kmPerPixel — масштаб измерения.
Новые поля создаются по мере использования соответствующих функций.
Исходный data/atlas.json не изменялся при установке 4.0.

Исходные код, стили и JSON 3.9 находятся в backups/v3.9-before-v4/.
Это резерв исходных файлов, а не самостоятельная копия всего проекта:
изображения maps/ не дублировались. Для возврата сначала скопируйте текущий
проект целиком, затем восстановите из этой папки index.html, README.txt,
css/, js/ и при необходимости data/atlas.json в корень исходного проекта.

ПРОВЕРКИ ДЛЯ РАЗРАБОТКИ
tests/regression.cjs запускается через Node.js; ATLAS_TEST_PYTHON задаёт путь
к Python для HTML-парсера. Дополнительные пакеты не требуются.
tests/main-folder.cjs проверяет запоминание папки, восстановление разрешений,
ошибки хранилища и защиту текущих изменений от запоздалой автозагрузки.
Проверки используют симуляцию DOM, Leaflet и файловой системы; они не
открывают браузер и не изменяют пользовательские данные.
Проверено: миграция, сохранение камеры при undo, поиск, карточки и статьи,
очистка HTML, просмотр, измерения, математика совмещения, порядок слоёв,
резервирование и ошибки записи, внешние изменения и правки во время записи.

Встроенный браузер среды разработки запретил открытие file://.
Визуальная проверка в Opera GX не выполнялась. Перед большой рабочей сессией
проверьте на копии папки: обычный и Ctrl-зум, перетаскивание и Shift-размер,
поворот 0/30/90°, отсутствие скачков регионов, обе карты окна совмещения,
форматирование и вставку картинки в статью, разрешение на папку и сохранение
с повторным открытием проекта. Запуск приложения по-прежнему не требует
установки инструментов разработки.
