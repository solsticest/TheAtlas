# Mythos v2 — рабочее пространство метафизики

Путь: `/mythos`. `/bible` оставлен совместимым алиасом.

## Представления

### Связи
Свободный граф божественных сущностей. Узлы сохраняют положение в БД. Связи направленные и типизированные:
- происхождение;
- союз;
- конфликт;
- служение / иерархия;
- воплощение / тождество;
- произвольная связь.

Граф имеет переключаемые слои: реальные связи, происхождение, политика, общие домены и пантеоны.
Есть автоматическая генеалогическая раскладка по связям происхождения.
У связи можно задать абсолютные дни начала/конца, поэтому граф способен показывать историческое состояние отношений.

### Таблица
Сортируемый обзор: природа сущности, фактическая сила, влияние 0–100, пантеон, домены и миры.
Отдельный режим «Матрица доменов» показывает основные и второстепенные домены для всех отфильтрованных сущностей.

### Энциклопедия
Карточки и подробная боковая панель. Карточка сущности агрегирует объективное описание, связи, мифы, культурные интерпретации, святыни Atlas и историю Chronicle.

### Предания
Четыре связанных слоя:
- мифы — один текст с несколькими участниками и ролями;
- верования — культурное имя/учение отдельно от объективной сущности, включая ошибочную идентификацию;
- святыни — связь сущности с конкретной Location Atlas;
- история — связь сущности с ChronicleEvent.

### Космология
Отдельный свободный граф планов, миров, посмертий, метафизических областей и путей между ними.
Космологические узлы не смешиваются с божествами, но могут быть привязаны к миру Atlas.

## Доступ
Все основные сущности используют `draft / gm / public`.
Публичные API дополнительно не раскрывают скрытые связанные сущности.
Изменение и удаление существующих записей создаёт резервную копию SQLite.

## Иерархия
`rank` описывает природу / онтологический класс сущности.
`power` — свободное описание фактического статуса силы.
`influence` — условный показатель 0–100 для сравнения и сортировки.
Это намеренно разные параметры.

## Миграции
v2 добавляет только новые таблицы/колонки и не удаляет существующие данные:
- `20261119000200_mythos_workspace`
- `20261119000300_mythos_hierarchy`

Перед локальным применением рекомендуется `npm.cmd run backup:atlas`, затем `npm.cmd run db:setup`.
