# Mythos — первый рабочий модуль

Веб-путь: `/mythos`. Для старых ссылок `/bible` отображает ту же страницу.
Название **Mythos** пока рабочее — можно переименовать без миграции данных.

## Возможности v1
- Каталог божеств: имя, титул, произвольный ранг/природа, домены, символ, цвет, аннотация, предание.
- Один бог может принадлежать нескольким мирам Atlas или быть общим для мультивселенной.
- Пантеоны: название, история, связь с одним миром или мультивселенной; одно божество может входить в один пантеон (ограничение v1).
- Поиск по описанию, имени, эпитетам и доменам; фильтры по мирам, пантеонам и доменам.
- Отдельный публичный просмотр; роли видимости `draft`, `gm`, `public`.
- Только администратор может создавать, редактировать, удалять. CSRF обязателен; перед обновлением и удалением сервер создаёт backup.
- Пантеон с присоединёнными божествами нельзя удалить — сначала перенесите их.
- Нет пользовательских HTML-инъекций: предания хранятся и отображаются как обычный текст.
- Домены в v1 — именованные метки внутри божества; существующие названия предлагаются в редакторе, повторы без учёта регистра объединяются.

## Что пока не реализовано
- Полноценная карта космологии и планы мироздания;
- связи божеств (родство, конфликты, союзы, влияние) и граф отношений;
- мультипантеонная принадлежность, изображения и эмблемы;
- связи с записями Chronicle и объектами Atlas;
- автоматическая генерация доменов/богов.

## Локальный старт
Остановить сервер `Ctrl+C`. После `git pull --ff-only` один раз применить новую **аддитивную** миграцию БД командой `npm.cmd run db:setup` перед `npm.cmd run dev`.
Предварительно рекомендуется `npm.cmd run backup:atlas`. Legacy JSON, существующие таблицы, карты и Chronicle миграция не удаляет.

Пантеонная таксономия намеренно не зашита списком. Это помогает избежать огромного количества однотипных божеств: автор сам определяет классификацию, а уже используемые домены видны рядом с редактором.
