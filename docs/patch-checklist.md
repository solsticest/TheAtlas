# Патчевая приёмка The Atlas на Windows

Проверка производится позднее, после согласования контрольного коммита. До этого не нужно перетягивать ветку на диск D: после каждого коммита.

## Подготовка

1. Закрой старый и новый Atlas; убедись, что старые изменения из браузера записаны на диск.
2. Сохрани отдельно исходные `data/atlas.json`, `maps/`, `media/` (если есть), текущие `storage/atlas.db`, `storage/assets/` и `.env` **вне каталога клонирования**. Ни один из этих файлов не отправляй в GitHub.
3. Перед проверкой редактора в новом интерфейсе сделай `npm.cmd run backup:atlas`.
4. Все команды выполняй из `D:\Projects\TheAtlas` в PowerShell.

## Подтянуть стабильный патч (после того как GitHub Actions зелёный)

```powershell
cd D:\Projects\TheAtlas
git switch feat/react-atlas-migration
git pull --ff-only
npm.cmd install
npm.cmd run db:setup
npm.cmd run import:atlas -- --verify
npm.cmd run typecheck
npm.cmd run test:alignment
npm.cmd run test:layer-editor
npm.cmd run dev
```

Если импорт уже происходил, `--apply` **не повторяй**. Если локальная база уже редактировалась, результат `verified-edited` ожидаем.

## Публичная карта

- [ ] Элдран, исходная PNG-карта 3840×2160.
- [ ] Линвейл и Грейфорд: вложенность, позиция и независимый rotation.
- [ ] Плавность дробного zoom, затухание слоёв, отсутствие скачков при увеличении.
- [ ] Эстара: маркер, описание, HTML-статья, теги.
- [ ] Поиск по слову «синдикат», переключение другого мира и фокусировка.
- [ ] Скрытие/показ типов маркеров.
- [ ] Демонстрационный мир с SVG-картами.
- [ ] Прямой URL с `?world=...&timeline=...&era=...` открывает правильный мир/эпоху.

## Редактор /admin

- [ ] Вход правильным паролем, отказ с неправильным, выход.
- [ ] Миры, карты, локации и типы: создание, открытие, редактирование.
- [ ] Создание отдельного тестового таймлайна с двумя эпохами и разными событиями; публикация и переключение без перезагрузки карты.
- [ ] Черновики не видны публичному посетителю.
- [ ] В существующей карте: «Переместить / изменить размер на карте» — изменяет только draft до «Сохранить».
- [ ] «Совместить изображение по двум точкам» — сравнить результат с legacy.
- [ ] Отменить/вернуть несколько правок формы до сохранения.
- [ ] Перед обновлением существующей записи появился новый полный snapshot в `storage/backups`.
- [ ] После перезагрузки браузера сохранённая правка осталась в SQLite.
- [ ] Проверка на узком экране (DevTools или телефон).
- [ ] Проверка восстановления копии **в отдельную пустую папку**, а не поверх рабочей базы.

## Если что-то не совпадает

Не правь `atlas.json` вручную и не удаляй `storage/`. Сохрани URL, консоль браузера (F12) и вывод PowerShell. Для геометрии приложи два скриншота одной области — из legacy и React при близком масштабе.

**Главное ограничение:** local undo/redo формы — не глобальный Undo оригинального Atlas. Миграционную ветку не сливать в `main` до успешной приёмки.
