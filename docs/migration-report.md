# Отчёт миграции — The Atlas

Рабочая ветка: feat/react-atlas-migration. Ветку main не изменяли.

## Контроль исходника

Исходный data/atlas.json — версия 4, SHA-256: 3a20704af9d3d5c22b7fcbb9f6a93bb85a83c470bd5799071fe139ae8d48f7de.

Проверены 2 мира, 7 типов маркеров, 3 карты-слоя, 5 локаций, 1 статья, 5 изображений карт и 0 медиа статей. Перечень UUID, parentId, точных bounds/rotation, размеров изображений и контрольных сумм: docs/migration-manifest.json.

Контрольные сущности: Элдран, Линвейл, Грейфорд, Эстара. Уточнение: bounds Грейфорда относятся к Линвейлу, а не к базовой карте Элдрана.

## Реализовано

Новое npm workspace, React/TypeScript/Vite/MUI, Leaflet viewer, RTK Query, Express/Zod, Prisma/SQLite. Read-only importer и транзакционный импорт с внешним backup и round-trip. Публичный просмотр карты и статей, поиск и фильтры. Timeline/Era/Event без выдуманного контента, черновики/публикации. Админка с авторизацией, серверная проверка мутаций, загрузки карт и медиа, ручное резервирование/восстановление.

Новый пользовательский контент после редактирования помечает SQLite как изменённую. Проверка импорта более не требует совпадения живой БД с неизменённым исходным JSON. Старый JSON сохраняется для rollback.

## Подтверждено автоматически

Старые regression tests, проверка сохранности источника, импорт без дубликатов, проверка всех SHA изображений, геометрические тесты, API-выдача и запрет неавторизованной записи, скрытие черновиков, типизация, сборка, lint, тест резервного копирования и восстановления.

Проверки доступны в GitHub Actions. Визуальное поведение в настоящем Windows-браузере не подтверждено автотестами; его нужно принять отдельно.

## Не завершено / нельзя считать полной паритетностью

- Полное визуальное совпадение вращения и анимации nested overlays, адаптивность, действия мышью.
- Редактирование слоя drag/resize на карте, совмещение по двум точкам, расширенная история undo/redo.
- Деплой на конкретную публичную платформу, внешний HTTPS и мониторинг.

**Решение:** не сливать в main и не удалять оригинальные файлы, storage или backups до согласованной ручной приёмки патчей.

Релизный smoke-test проверяет, что Express отдаёт собранные страницы / и /admin, а API сохраняет JSON-маршруты. Для запуска: npm.cmd run build, затем npm.cmd start с NODE_ENV=production. Реальный HTTPS-хостинг ещё не выбран.
