# Архитектура The Atlas

Браузер → React/Vite + MUI + Leaflet + RTK Query → Express API → Prisma → SQLite.

- apps/web: публичная карта / и редактор /admin. Leaflet работает с L.CRS.Simple и пиксельными координатами, а не широтой/долготой.
- apps/api: Express, GET-маршруты, серверная валидация Zod, один администратор с bcrypt и HttpOnly cookie, CSRF, загрузка изображений, backup.
- packages/shared: общие Zod-схемы и TypeScript-типы.
- apps/api/prisma: модели и последовательные аддитивные миграции SQLite.
- storage/atlas.db: рабочая база; storage/assets/: изображения; storage/backups/: снимки. Всё вне Git.
- data/atlas.json, maps/, js/, index.html: сохранённый оригинал v4.1 и откат.

## Исходная геометрия

Bounds дочернего слоя хранятся в пикселях родителя и рекурсивно конвертируются в координаты мира. Дробные величины не округляются. Визуальный rotation не наследуется дочерними картами. Для сохранения точности в SQLite рядом с типизированными колонками сохраняется исходный raw JSON как текст. При смене эпохы основная Leaflet map остаётся той же: обновляются только исторические маркеры.

## Домен

World → MapLayer/Location и Timeline → Era → Event. Событие связано с эпохой, опциональной локацией и координатами. Для публичных GET отбираются опубликованные таймлайны и события, а черновики доступны только /api/admin/*.

World, MarkerType, MapLayer, Location хранят оригинальные ID, параметры геометрии и raw JSON. MediaAsset хранит хеш, размер, безопасный путь. Оригинальные PNG/WebP/SVG не сохраняются в тексте БД.

## Безопасность

Пароль хранится только как bcrypt-хеш в локальном .env. Сессия подписана HMAC и отзывается через SQLite, cookie HttpOnly, SameSite=Strict, Secure под HTTPS. На всех маршрутах администрирования проверяется сессия и CSRF. Контент HTML очищается на сервере и при отображении; загрузка ограничена типом и размером. Файлы выдаются только из списка MediaAsset и только из проверенной директории.

SQLite backup создаётся с помощью VACUUM INTO — согласованная копия даже при включённом WAL — вместе со снимком assets и SHA-256 manifest. Восстановление по умолчанию разрешается только в новую папку.

## Развёртывание и ограничения

SQLite требует постоянное файловое хранилище; для эфемерного хостинга нужны отдельные Postgres/объектное хранилище. Перед production обязательно HTTPS и проверка proxy/session. Отображение и формы реализованы, но legacy drag/resize и двухточечная подгонка не считаются перенесёнными до отдельной работы и визуального тестирования.

## Redux и редактор геометрии

В Redux slice `atlasView` хранятся выбранный мир, таймлайн, эпоха, фильтры типов и запрошенный фокус камеры; RTK Query хранит серверные списки. Интерактивный редактор слоя работает в координатах *непосредственного родителя* и изменяет только несохранённый draft. `atlasMath.ts` точно повторяет `js/atlas-math.js`; `layerEditorMath.ts` гарантирует положительные размеры bounds. Локальные 60 undo-снимков формы сбрасываются после сохранения или смены записи.
