Windows-приёмка основных сценариев выполнена; решение: **Local RC1**, без гарантии глобального Undo, performance/parity и production. См. [отчёт приёмки](acceptance-windows-2026-11-06.md).

Перед **каждым обновлением или удалением** существующих сущностей создаётся полный снимок SQLite и assets. Много правок требует места на диске D:; хранение и очистку backup выполняет владелец вручную.


## Контекстный редактор основной карты

После Local RC1 интерфейс переработан: отдельный глобальный режим редактирования удалён. Авторизация только разблокирует конкретные действия.

- Постоянная command bar: поиск, + Маркер, + Регион, + Событие, + Тип маркера; при открытом черновике — Undo/Redo, Save/Cancel и индикатор dirty-state.
- ЛКМ по маркеру открывает короткую карточку; статья открывается только через «Подробнее». Маркер и статья имеют отдельные команды редактирования.
- ПКМ по пустой карте, маркеру, событию и региону даёт контекстные create/edit/move/duplicate/delete действия.
- Маркер и событие можно поставить кликом по карте. Маркер становится draggable только после явной команды «Переместить».
- Регион после загрузки изображения показывается полупрозрачным draft-overlay; центр и углы перетаскиваются прямо на основной карте. Вложенный регион можно создать из контекста родителя.
- Дублирование создаёт черновик, а не немедленную запись.
- Live-preview поддерживает координаты/значки маркера, события, положение региона и оформление существующего типа маркеров.
- Тип маркера: имя, цвет и ровно один значок — эмодзи/символ или серверно проверенный SVG.
- `/admin` сохранён как технический табличный fallback.
- При открытом drawer Undo/Redo работает по черновику; при закрытом — по постоянной истории уже сохранённых marker/layer/event/type операций. Новая правка после Undo очищает ветку Redo. Перед серверным Undo/Redo создаётся backup.

Автоматические проверки подтверждают API, миграции, SVG-фильтрацию, backup, сборку и постоянный Undo/Redo маркера. Таймлайны и эпохи намеренно пока не входят в глобальную историю. Новый UX основной карты должен пройти отдельную ручную Windows-приёмку перед новым релизным решением.
