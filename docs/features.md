# Совместимость legacy v4.1 и новой версии

| Функция | Статус | Проверка |
|---|---|---|
| 2 мира, 3 слоя, 5 локаций, 7 типов | Перенесены | Dry-run, round-trip SQLite |
| 5 исходных карт и оригинальные UUID | Перенесены | SHA-256, пути, файлы |
| Вложенность Линвейл → Грейфорд | Перенесена | Геометрические тесты |
| Дробный zoom/rotation/появление слоёв | Реализовано | CI + ручная проверка на Windows; попиксельная сверка не проводилась |
| Маркеры, поиск, статьи и фильтры | Реализовано | API + ручная приёмка |
| Публичный просмотр без записи | Реализовано | Тест авторизации API |
| Таймлайны, эпохи и публикация событий | Новая функция | API, React, тест скрытия черновиков |
| Миры, слои, локации, типы: CRUD | Реализовано | Авторизованные API и формы |
| Выбор точки на карте | Реализовано | Ручной тест не прошёл изначально; после патча e6600ffe пройден |
| Защита администратора, CSRF и login rate limit | Реализовано | Интеграционный тест |
| Полный backup SQLite + assets и restore | Реализовано | Manifest/SHA-256, тест восстановления |
| Undo/redo редактора | Частично: до 60 снимков активной формы | Глобальная история между объектами пока legacy |
| Drag/resize карты в координатах родителя | Реализовано в форме слоя | CI + ручная проверка мышью пройдена |
| Подгонка изображения по двум точкам | Реализовано в редакторе слоя | Математика сверена с v4.1 + ручная проверка пройдена |
| Автоматический продакшен-хостинг | Не выполнено | Нужна выбранная площадка |

Windows-приёмка основных сценариев выполнена; решение: **Local RC1**, без гарантии глобального Undo, performance/parity и production. См. [отчёт приёмки](acceptance-windows-2026-11-06.md).

Перед **каждым обновлением или удалением** существующих сущностей создаётся полный снимок SQLite и assets. Много правок требует места на диске D:; хранение и очистку backup выполняет владелец вручную.
