# Руководство администратора

## Вход

В PowerShell из D:\Projects\TheAtlas запусти npm.cmd run admin:setup и укажи пароль длиной от 12 символов. Затем npm.cmd run dev. В браузере открой http://localhost:5173/admin и введи пароль. Публичных аккаунтов и регистрации нет.

Пароль не хранится в браузерном JS. Сессия — HttpOnly cookie; изменение данных требует проверки CSRF на сервере. Ссылка на карту находится вверху редактора.

## Создать историю

1. В верхней панели выбери мир.
2. Перейди на вкладку «Таймлайны», нажми «Создать», впиши название, описание и порядок. Установи «Опубликовано», когда история готова.
3. Выбери таймлайн и перейди на «Эпохи». Задай название, подпись периода, порядок и описание.
4. Выбери эпоху, вкладку «События», нажми «Создать». Заполни название, краткое описание, статью, теги, категорию и дату-подпись. Черновики скрыты от посетителей.
5. Для геопозиции выбери существующую локацию либо используй кнопку «Выбрать координаты на карте». Координаты X/Y — система конкретного мира, а не Земли. Если локация и координаты отсутствуют, событие показывается в списке.
6. Нажми «Сохранить», затем проверь в публичном интерфейсе при нужной эпохе.

Ссылки на мир/таймлайн/эпоху сохраняются в URL. Исторические события разных эпох переключаются, не сбрасывая обычную карту.

## Миры, слои, типы маркеров и локации

Выбери вкладку, затем существующий элемент в левом списке или «Создать». Параметры слоя bounds заданы **в координатах родительского изображения**. Поворот слоя не переносится на детей. Не вводи широту или долготу. Все старые ID сохраняются при редактировании.

Для изображения выбери категорию «Карты» или «Статьи» и загрузи PNG/WebP/JPEG до 40 МБ. Сервер создаёт безопасное уникальное имя и записывает его в поле текущей формы. Исходные файлы maps/ не перезаписываются.

HTML-статьи очищаются на сервере: скрипты и обработчики событий не допускаются.

## Удаление, несохранённые данные, восстановление

Перед уходом с изменённой формы показывается предупреждение. «Удалить» требует подтверждения; при наличии зависимых объектов сервер отказывает и сохраняет данные. Перед разрешённым удалением создаётся backup базы и assets.

Создать отдельный backup вручную: npm.cmd run backup:atlas. Проверить восстановление: команда из README с --restore в новую папку. Не удаляй storage/, .env или внешнюю папку TheAtlas-Backups при ошибках. Вместо этого сохрани текст ошибки.

## Что ещё зависит от legacy

Полное перемещение/изменение размера картинки мышью, подгонка по двум точкам, undo/redo редактора и ряд старых инструментов ещё требуют переноса. Пока используй оригинальную v4.1 для этих операций, сохраняя отдельную копию; новая SQLite не синхронизируется со старым JSON автоматически.
