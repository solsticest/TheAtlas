# Новый Atlas Viewer (React) — запуск на Windows

Ветка: feat/react-atlas-migration. Новый интерфейс пока **только для просмотра**. Legacy не удалён.

## Обновление на диске D:

Если сервер запущен, нажмите Ctrl+C в его PowerShell. Затем:

```powershell
cd D:\Projects\TheAtlas
git switch feat/react-atlas-migration
git pull --ff-only
npm.cmd install
npm.cmd run db:setup
npm.cmd run import:atlas -- --verify
npm.cmd run dev
```

При успешной команде --verify повторять импорт с --apply не нужно. SQLite уже содержит данные, а резервная копия есть в D:\Projects\TheAtlas-Backups.

Открыть http://localhost:5173. Также API работает по адресу http://localhost:3001/api/health.

## Что должно появиться

- Тёмная панель The Atlas.
- Слева выбор мира, поиск, список карт, фильтры типов, список локаций.
- Справа настоящие карты Leaflet из SQLite и ранее скопированных изображений.

## Проверка в браузере

1. Выберите мир «Элдран». Должна загрузиться большая карта 3840×2160.
2. Нажмите в списке «Линвейл», затем «Грейфорд»; сравните размеры, вложенность и поворот со старой версией.
3. Приближайте и отдаляйте колесом: подробные слои должны появляться постепенно.
4. Выберите локацию «Эстара». Камера перейдёт к маркеру; в карточке нажмите «Подробнее».
5. Должны появиться исходное описание, статья и теги.
6. Введите в поиск «синдикат», а затем «Грейфорд». Попробуйте перейти к результатам.
7. Отключите тип «Город» и включите обратно. Проверьте видимость маркеров.
8. Переключитесь в демонстрационный мир и проверьте SVG-карты.

## API для диагностики

- http://localhost:3001/api/worlds — 2 мира
- http://localhost:3001/api/types — 7 типов
- http://localhost:3001/api/search?q=Эстара — результат поиска

Если появляется DATABASE_NOT_READY, сначала проверьте, что база создана и импорт выполнен.

## Автоматические проверки

```powershell
npm.cmd run typecheck
npm.cmd run test:geometry
npm.cmd run test:api
npm.cmd run build
```

Команды тестирования базы создают временные файлы отдельно от рабочего storage/atlas.db.

## Ограничения

- Пока только чтение. Нет новой админки и авторизации.
- Новая SQLite-база **не синхронизируется** автоматически с изменениями в старом data/atlas.json.
- Анимацию, вращение и поведение мыши требуется сравнить вручную с legacy в Chrome/Opera GX.
- Chronicle и таймлайны будут отдельной последующей разработкой.
- Исходные index.html, js/, data/, maps/ не удаляются; старый Atlas остаётся вариантом отката.
