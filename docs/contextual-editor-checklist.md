# Приёмка contextual editor — Windows

Эта проверка относится к UX-итерации после Local RC1. Старые 38 ручных сценариев не подтверждают новый интерфейс автоматически.

## Подготовка

1. Остановить dev-сервер.
2. Сделать backup текущей SQLite + assets.
3. Подтянуть ветку и применить только additive Prisma migration:
   ```powershell
   cd D:\Projects\TheAtlas
   npm.cmd run backup:atlas
   git pull --ff-only
   npm.cmd run db:setup
   npm.cmd run dev
   ```
4. Не запускать повторный `import:atlas -- --apply`.

## Основной сценарий

- [ ] Верхняя панель всегда показывает Поиск, + Маркер, + Регион, + Событие, + Тип маркера.
- [ ] Нажатие инструмента до входа открывает login и после успешного входа продолжает выбранное действие.
- [ ] ЛКМ по Эстаре открывает только короткую карточку; статья не открывается автоматически.
- [ ] «Подробнее» закрывает карточку и открывает статью.
- [ ] В карточке администратора есть «Редактировать маркер»; в статье — «Редактировать статью».
- [ ] Редактор маркера не смешивает полную статью с координатами/типом; редактор статьи показывает только статью.
- [ ] ПКМ по пустому месту: создать маркер, создать событие, добавить регион, скопировать координаты.
- [ ] ПКМ по маркеру: подробнее, edit marker/article, move, duplicate, delete.
- [ ] ПКМ по событию и региону показывает их контекстные действия.
- [ ] + Маркер → клик по карте → появляется draft preview; Save создаёт объект, Esc/Cancel не создаёт.
- [ ] «Переместить маркер» делает draggable только выбранный маркер; Cancel возвращает сохранённые координаты.
- [ ] + Событие использует текущую эпоху и создаёт draft в выбранной точке.
- [ ] + Регион → загрузка изображения → полупрозрачный preview с угловыми и центральной ручками прямо на основной карте.
- [ ] Drag/resize региона обновляет draft; Cancel возвращает исходную карту; Save фиксирует.
- [ ] «Добавить вложенную карту» из контекста региона автоматически назначает родителя.
- [ ] Дублировать маркер/событие/регион создаёт черновик; до Save в SQLite ничего не появляется.
- [ ] Ctrl+S сохраняет; Esc отменяет; Ctrl+Z/Ctrl+Y работают для текущей операции, включая marker drag и region resize.
- [ ] После Save и закрытия drawer ↶/Ctrl+Z отменяет последнее сохранённое действие маркера/региона/события/типа; ↷/Ctrl+Y повторяет.
- [ ] Цепочка: создать тестовый маркер → Save → переместить → Save → Ctrl+Z возвращает старую позицию → Ctrl+Z удаляет созданный маркер → два Redo восстанавливают создание и перемещение.
- [ ] Новое сохранённое действие после глобального Undo очищает доступный Redo.
- [ ] При изменении существующего типа маркеров цвет/иконка временно меняются на карте; Cancel возвращает исходные.
- [ ] + Тип маркера позволяет создать цветной emoji/symbol тип.
- [ ] + Тип маркера позволяет загрузить SVG; безопасный SVG отображается как значок.
- [ ] После Save карта сохраняет текущий центр/zoom и не прыгает к виду всего мира.
- [ ] Кнопки «…» у локаций/регионов появляются на hover/focus; touch-вариант остаётся доступным.
- [ ] Смена мира/таймлайна/эпохи при dirty draft запрашивает подтверждение.

## Ограничение этой итерации

Постоянный глобальный журнал сейчас охватывает маркеры, регионы, события и типы маркеров. Таймлайны/эпохи пока используют только историю текущего открытого черновика: для корректного глобального отката их default/sibling-состояния нужен отдельный составной snapshot.
